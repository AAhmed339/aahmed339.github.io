# تعليمات رفع الموقع إلى GitHub Pages

المستودع: https://github.com/AAhmed339/aahmed339.github.io
الموقع: https://aahmed339.github.io

هذه الحزمة تضم ملف index.html وصورًا إضافية يجب وضعها جميعًا في المجلد الرئيسي (Root) للمستودع، بجوار الصور الموجودة بالفعل.

1. افتح المستودع ثم Add file → Upload files.
2. ارفع كل الملفات الموجودة في الحزمة بعد فك الضغط (وليس ملف ZIP نفسه).
3. عند ظهور الملف index.html القديم سيتم تحديثه بالنسخة الجديدة عند Commit changes.
4. اترك بقية الملفات القديمة الموجودة مسبقًا في المستودع دون حذف.
5. بعد اكتمال النشر افتح الموقع ونفّذ Ctrl+F5 إذا ظهر الإصدار القديم.

مهم: لا يكفي رفع index.html وحده لأن الصور الجديدة ملفات خارجية.
الصور والشهادات المعروضة في الموقع قابلة للعرض ولكن لا يمكن منع تنزيل الملفات من مستودع GitHub عام.
يرجى التأكد من إخفاء أرقام الهوية أو البيانات الحساسة من ملفات JPG الأصلية قبل نشرها للعامة؛ النسخة المرفقة من البكالوريوس منقحة.
